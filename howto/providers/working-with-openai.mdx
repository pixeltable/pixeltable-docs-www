## Azure OpenAI

The same functions call Azure OpenAI. `OPENAI_API_KEY` is the Azure key,
and `OPENAI_BASE_URL` is the resource endpoint, passed through as the
client’s `base_url`. `OPENAI_API_VERSION` is sent as the `api-version`
query parameter; for the `/openai/v1/` endpoint use `preview` or
`latest`. The `model` argument is the deployment name on that resource.

## Responses API

The [Responses
API](https://developers.openai.com/api/docs/api-reference/responses) is
OpenAI’s recommended API for new projects. It offers built-in tools (web
search, file search, code interpreter), improved reasoning model
performance, lower costs, and cleaner semantics compared to Chat
Completions.

Key benefits:

- **`instructions` parameter**: Cleanly separates system-level guidance
  from user input
- **Built-in tools**: Use `web_search`, `file_search`,
  `code_interpreter` natively
- **Multi-turn via `previous_response_id`**: Simpler conversation state
  management


```python
# Create a table and add a computed column using the Responses API

resp_t = pxt.create_table('openai_demo/responses', {'input': pxt.String})

messages = [{'role': 'user', 'content': resp_t.input}]
resp_t.add_computed_column(
    output=openai.responses(
        input=messages,
        model='gpt-4o-mini',
        model_kwargs={
            'instructions': 'You are a helpful assistant. Be concise.',
            'temperature': 0.7,
            'max_output_tokens': 300,
        },
    )
)

# The response text is the first content part of the first output item
resp_t.add_computed_column(
    response=resp_t.output.output[0].content[0].text
)
```

## Decisions

The [Decisions
API](https://developers.openai.com/api/docs/guides/decisions) answers
predicate, choice, and score questions about a text or image input. Each
answer is a probability, a choice, or a score instead of generated text.
`decisions()` requires `openai>=3.32`.

This example checks food-delivery complaints against the customer’s
photo. A `reply_prompt()` UDF returns `None` unless the photo supports
the complaint, and a `None` input skips the `responses()` call, so only
supported complaints get a drafted reply.


```python
@pxt.udf
def reply_prompt(complaint: str, supported: float | None) -> list | None:
    if supported is None or supported < 0.5:
        return None
    return [
        {
            'role': 'user',
            'content': f'Draft a two-sentence apology with a refund for: {complaint}',
        }
    ]


dec_t = pxt.create_table(
    'openai_demo/complaints',
    {'complaint': pxt.String, 'photo': pxt.Image},
)
messages = [
    {
        'role': 'user',
        'content': [
            {'type': 'input_text', 'text': dec_t.complaint},
            {'type': 'input_image', 'image_url': dec_t.photo},
        ],
    }
]
questions = [
    {
        'type': 'predicate',
        'name': 'supported',
        'instructions': "Does the photo support the customer's complaint?",
    },
    {
        'type': 'choice',
        'name': 'issue',
        'instructions': 'What is the complaint about?',
        'choices': [
            {'value': 'missing item'},
            {'value': 'unwanted item'},
            {'value': 'food quality'},
            {'value': 'other'},
        ],
    },
    {
        'type': 'score',
        'name': 'urgency',
        'instructions': 'How upset is the customer?',
        'levels': [
            {'label': 'calm'},
            {'label': 'annoyed'},
            {'label': 'angry'},
        ],
    },
]
dec_t.add_computed_column(
    triage=openai.decisions(
        messages, questions=questions, model='gpt-6-luna'
    )
)
dec_t.add_computed_column(supported=dec_t.triage.answers[0].probability)
dec_t.add_computed_column(issue=dec_t.triage.answers[1].choice)
dec_t.add_computed_column(urgency=dec_t.triage.answers[2].score)
dec_t.add_computed_column(
    reply=openai.responses(
        reply_prompt(dec_t.complaint, dec_t.supported),
        model='gpt-4o-mini',
    )
)
dec_t.add_computed_column(
    reply_text=dec_t.reply.output[0].content[0].text
)
```
